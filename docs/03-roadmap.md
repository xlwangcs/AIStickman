# 03 · 里程碑与任务拆分

每个里程碑结束时：`pnpm test` 全绿 + 浏览器可运行 + 提交并推送 GitHub。任务粒度按"一次 AI 会话可完成"设计。

## M0 · 脚手架（半天）

- [ ] Vite + TypeScript(strict) + pnpm 初始化，ESLint + Prettier
- [ ] 固定时间步主循环 `core/loop.ts` + 空白 Canvas 渲染心跳
- [ ] Vitest 接入，一个示例测试
- [ ] GitHub Actions：typecheck + test + build + Pages 部署
- [ ] git init、首次 push

**验收**：GitHub Pages 上能打开一个显示 FPS 的空画布。

## M1 · 灵魂原型：会站立、能甩矛的火柴人（1~2 天）⭐ 最关键

- [ ] Planck 世界 + 地面，`physics/world.ts`
- [ ] `ragdoll.ts`：头/躯干/轮足/手臂 + 关节装配，碰撞过滤
- [ ] `balance.ts` PD 站立控制器 + 失衡窗口
- [ ] 键盘输入 → PlayerIntent → 移动/跳跃/手臂指向
- [ ] 长矛焊接到手，甩动可视化调试（画出武器尖速度矢量）
- [ ] `tuning.ts` 集中所有手感参数 + 页面调参面板（dat.gui 风格自制）
- [ ] 无头测试：站立稳定性、受冲量恢复

**验收（人工）**：用键盘操作，甩矛"有惯性、有力量感"，被打会踉跄。此关不过不进 M2。

## M2 · 能打死人的 1v1（1~2 天）

- [ ] `contacts.ts` 命中事件（CCD + PostSolve 相对速度）
- [ ] `damage.ts` 伤害公式 + 单测；血量、死亡→全身布娃娃
- [ ] 击退 + 受击硬直；命中冷却
- [ ] 回合系统：出生点、死亡计分、3 秒重置、先到 5 分
- [ ] HUD：血条、比分；击杀慢动作 + 屏幕震动
- [ ] 无头 AI 互殴回归测试（固定种子 50 回合）

**验收**：键盘双人（WASD vs 方向键）能完整打完一场比赛。

## M3 · AI 对手（1 天）

- [ ] AI 状态机：接近/保距/甩击/回场/避险，输出 PlayerIntent
- [ ] 3 档难度参数（反应延迟、瞄准噪声、避险概率）
- [ ] 人机模式接入对局流程

**验收**：中等难度 AI 能打赢不专心的人类，简单难度能被新手打赢。

## M4 · 武器与地图扩展（1~2 天）

- [ ] 武器注册表重构，长矛参数化
- [ ] 双手剑（大弧度、高伤害、慢速）
- [ ] 弓 + 箭抛射体（按住跳跃键蓄力？——设计待定，见 ideas）
- [ ] 地图接口 + 3 张地图：竞技场悬崖 / 岩浆 / 移动平台+尖刺
- [ ] 环境杀判定与得分

**验收**：3×3 武器地图组合均可正常对局，无物理爆炸。

## M5 · 移动端与门面（1~2 天）

- [ ] 触屏浮动摇杆 + 跳跃区；同屏双人分区触控
- [ ] 主菜单/选择界面/结算界面（状态机接 UI）
- [ ] 相机双人跟随缩放打磨；粒子特效（血点、火花）
- [ ] WebAudio 程序化音效
- [ ] PWA manifest（可添加到主屏幕）
- [ ] 真机测试清单过一遍（iOS Safari / Android Chrome）

**验收**：手机浏览器完整游玩体验 ≈ 桌面端。→ **这就是 MVP 发布点**

## MVP 之后（按需排期）

生存模式 → 2v2 → 更多武器（锤/匕首/枪） → 皮肤颜色系统（localStorage） → 锦标赛 → Capacitor 打包上架 → （远期）确定性重构 + 回滚联机

## 手测清单（每次发布前）

1. 桌面 Chrome：键盘双人一整场
2. 手机竖屏打开 → 有横屏提示
3. 手机横屏：摇杆跟手、跳跃无误触；双人分区互不干扰
4. 每张地图打一回合：环境杀生效、无卡死
5. 击杀慢动作、音效、比分正确
