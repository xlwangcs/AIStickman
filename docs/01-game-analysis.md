# 01 · 参考游戏玩法拆解 —— Supreme Duelist Stickman

> 目的：把原作"好玩"的来源拆解为可实现、可验证的机制清单。我们做的是玩法致敬，不复刻其美术/名称/资产。

## 1. 核心循环

```
选武器/地图 → 回合开始 → 移动+甩动武器互殴 → 一方死亡（击杀或环境杀）→ 得分 → 下一回合 → 先到 N 分获胜
```

回合极短（5~30 秒），失败无惩罚，"再来一局"欲望极强。这是它成功的第一支柱。

## 2. 角色与物理（第二支柱：手感）

原作角色是**主动驱动的布娃娃**（active ragdoll）：

| 状态 | 表现 | 实现要点 |
| --- | --- | --- |
| 存活站立 | 保持直立、脚贴地滑动、身体随移动倾斜 | 躯干施加"扶正力矩"（balance motor），腿不做真实步行，用胶囊体滑动 + 程序化摆腿动画 |
| 持械 | 手臂带着武器指向摇杆方向，快速转向时武器产生大角速度 | 手臂 RevoluteJoint + 马达追踪目标角度，武器刚性绑在手上 |
| 受击 | 关节瞬间失去马达力，整体被击飞，随后恢复 | 命中后 N 毫秒关闭 balance/arm 马达（"失衡窗口"） |
| 死亡 | 完全布娃娃，飞出/瘫倒 | 永久关闭所有马达，头部脱落彩蛋可选 |

**攻击不是按键触发的**：武器伤害来自物理——武器尖端相对目标的速度越大伤害越高。玩家通过"甩摇杆"让手臂马达带动武器高速旋转来打人。这一条是整个游戏的灵魂，必须最优先原型验证。

## 3. 操作

- 左侧虚拟摇杆：水平移动 + 决定武器指向（摇杆方向 = 手臂目标角度）
- 右侧单键：跳跃（部分武器为二段跳/技能）
- 同屏双人：屏幕左右各一套摇杆+按键
- 桌面端映射：P1 = WASD + F；P2 = 方向键 + 右 Ctrl（或 J/K）

## 4. 伤害与击杀

- 伤害 = f(武器攻击部位与目标的相对速度, 命中部位系数)；头部系数最高
- 命中产生大幅击退 + 失衡窗口 → 连招空间来自"打飞后追击"
- 环境杀：岩浆/尖刺/出界即死，与武器击杀同分
- 两种胜负模式：一击必杀 / 血条模式（MVP 先做血条 + 可选一击必杀开关）

## 5. 武器（MVP 选 3 种，覆盖三类手感）

| 武器 | 类型 | 特征 |
| --- | --- | --- |
| 长矛 | 长杆戳刺 | 距离长、甩动惯量大，原作默认武器 |
| 双手剑 | 中距挥砍 | 判定弧大、伤害高、速度中等 |
| 弓 | 远程 | 拉弓蓄力放箭，箭是物理抛射体，近身弱 |

后续扩展：锤（超高击退）、匕首（快但短）、枪、镰刀、法杖等。

## 6. 地图（MVP 选 3 张，覆盖三类环境杀）

1. **平台竞技场**：两侧悬崖出界杀（教学地图）
2. **岩浆地板**：中央窄平台 + 底部岩浆
3. **移动平台**：往复移动的平台 + 尖刺墙

后续扩展：低重力、传送门、风场、可破坏地形。

## 7. 模式

- MVP：1v1 人机（3 档难度）、同屏 1v1 双人
- 后续：2v2、生存（连续车轮战）、锦标赛（8 人淘汰赛，AI 填充）
- 在线对战：明确**不在** MVP 范围（需要确定性物理 + 回滚网络，成本极高）

## 8. AI 对手行为拆解

原作 CPU 行为可归纳为状态机：**接近 → 保持武器有效距离 → 甩武器 → 被打飞后回场 → 避开环境危险**。
三档难度通过反应延迟、瞄准误差、危险规避概率区分。

## 9. 留存系统（MVP 之后）

皮肤颜色自定义 → 武器/地图解锁 → 每局金币 → 商店。全部本地存储（localStorage），无账号体系。
